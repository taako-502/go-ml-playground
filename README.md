# go-ml-playground

Goの標準ライブラリだけで、機械学習の学習処理を実装する実験用リポジトリ。

## 01: 線形回帰で住宅価格を予測する

Go 1.22以降で実行できます。追加パッケージやデータのダウンロードは不要です。

```sh
go run ./cmd/linear-regression
go test ./...
```

面積を入力し、価格を予測します。住宅データは架空で、実際の不動産価格を推定するものではありません。

### 読む順番

`cmd/linear-regression/main.go` の `predict` → `mse` → `step` → `main` の順に読むと、予測・誤差・更新・学習ループを追えます。

1. `dataset` が「価格 = 30 × 面積 + 500 + ノイズ」で100件を生成します。単位は㎡と万円です。この係数を学習処理に渡すことはありません。
2. シャッフルし、80件を学習用、20件を評価用に分けます。
3. 重みと切片を0から始め、学習データの平均二乗誤差（MSE）を小さくする方向に更新します。
4. 更新を繰り返し、学習に使っていない20件で評価します。評価データはパラメータの更新に使いません。

### 学習で何が変わるのか

モデルは `予測価格 = w × x + b` です。`x = 面積 / 100` と固定倍率でスケーリングし、更新を安定させています。表示時は `w / 100` に戻します。例えば学習後の `w` が3000なら、面積1㎡当たりの係数は30です。

誤差を `e = 予測価格 - 正解価格` とすると、学習データn件に対して：

```text
MSE = Σ(e²) / n
dw  = 2 × Σ(e × x) / n
db  = 2 × Σ(e) / n
w   = w - 学習率 × dw
b   = b - 学習率 × db
```

`dw` と `db` は誤差が増える方向とその傾きを表す勾配です。その逆方向に少しずつ動かすのが勾配降下法です。全80件から勾配を計算した後に一度更新する処理を、ここでは1 epochと呼びます。

### 出力の見方

- 学習MSE：学習中に最小化する値。単位は万円の二乗です。
- 学習・評価RMSE：MSEの平方根。価格と同じ万円単位で誤差の大きさを見られます。絶対誤差の平均ではありません。
- 基準モデル：学習データの平均価格を常に返します。面積を使うモデルが単純な予測より改善したか比較します。
- 評価データの正解・予測：未知の入力に対する予測の具体例です。

ノイズがあるので、生成式の係数が厳密に復元されるとは限らず、誤差も0にはなりません。

### 実験

```sh
# ノイズなし：係数30、切片500に近づくか確認
go run ./cmd/linear-regression -noise 0

# 学習不足：デフォルトの2000回と比較
go run ./cmd/linear-regression -epochs 10

# 学習率を小さくする：同じ回数でも収束が遅くなる
go run ./cmd/linear-regression -lr 0.001

# 大きすぎる学習率：誤差が増大し、非有限値になったら異常終了
go run ./cmd/linear-regression -lr 2

# ノイズを増やす
go run ./cmd/linear-regression -noise 500

# データを変える／任意の面積を予測する
go run ./cmd/linear-regression -seed 123 -area 90
```

まず1つのパラメータだけを変え、MSEの減り方と評価RMSEを比較してください。生成する面積は20〜120㎡です。その範囲外の予測は外挿になります。

この例は「直線で生成したデータに直線を当てる」基礎実験です。過学習を観察するには、次の題材として少数データへの高次多項式回帰が適しています。評価結果を見ながら設定を何度も選ぶ場合は、検証用と最終テスト用を分ける必要があります。

### テスト

ノイズのないデータから既知の直線を復元できることと、更新に使う勾配が数値微分と一致することを検証します。
