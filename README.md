# go-ml-playground

**「気温を渡すと、アイスクリームの販売数を予測する」モデルを、Goでゼロから学習させる実験です。**

80件の架空データから直線を学び、学習に使わなかった20件で予測を評価します。機械学習ライブラリは使わず、予測・誤差の計算・勾配降下法までGoの標準ライブラリだけで実装しています。

## まずは実行結果を見てみる

```sh
go run ./cmd/linear-regression -html report.html
open report.html # macOS。他のOSではファイルをブラウザで開く
```

生成されるHTMLはCSS・JavaScript・実行データを含む単一ファイルです。サーバーやネット接続、npmのインストールは不要です。

| 画面 | わかること |
| --- | --- |
| 結果のサマリー | 気温を使った予測は、平均販売数だけを返す予測より良くなったか |
| 散布図と学習の再生 | 0から始まった直線が、日ごとの点に近づく様子 |
| 誤差のグラフ | 学習を繰り返すとMSEがどう変化するか |
| 気温の入力 | 学習後の式で任意の気温での販売数 |
| 評価20件の一覧 | 学習に使っていない日で、正解と予測がどれだけ違うか |

デフォルト設定の実行では、評価RMSEは **76.24個（平均販売数のみ）→ 12.66個（学習後）**。25℃の予測は約235.6個になります。これは架空データでの結果であり、実際の販売数の精度を示すものではありません。

設定を変えた結果も別ファイルで比較できます。

```sh
go run ./cmd/linear-regression -epochs 10 -html report-short.html
go run ./cmd/linear-regression -noise 50 -html report-noisy.html
```

HTMLの数値と学習曲線はGoの実行結果です。スライダーは記録した途中経過を表示し、気温入力だけをJavaScriptで再計算します。途中経過はファイルサイズを抑えるため約1,000点以内に間引き、初期値と最終値を必ず含めます。MSEの対数表示では0付近を10⁻¹²に丸めます。`-html`を省略すると従来どおり端末にだけ出力します。出力先に既存ファイルがある場合は上書きします。

## 01: 線形回帰でアイスクリームの販売数を予測する

Go 1.27以降で実行できます。追加パッケージやデータのダウンロードは不要です。

```sh
go run ./cmd/linear-regression
go test ./...
```

気温を入力し、販売数を予測します。日別の販売データは架空で、実際の販売数を推定するものではありません。線形回帰の仕組みに集中するため、販売数を連続値として扱い、整数への丸めや0での切り上げは行いません。大きなノイズや外挿では負の値になる場合もあります。

### 読む順番

`cmd/linear-regression/main.go` の `predict` → `mse` → `step` → `main` の順に読むと、予測・誤差・更新・学習ループを追えます。

1. `dataset` が「販売数 = 8 × 気温 + 40 + ノイズ」で100件を生成します。単位は℃と個です。この係数を学習処理に渡すことはありません。
2. シャッフルし、80件を学習用、20件を評価用に分けます。
3. 重みと切片を0から始め、学習データの平均二乗誤差（MSE）を小さくする方向に更新します。
4. 更新を繰り返し、学習に使っていない20件で評価します。評価データはパラメータの更新に使いません。

### 学習で何が変わるのか

モデルは `予測販売数 = w × x + b` です。`x = 気温 / 10` と固定倍率でスケーリングし、更新を安定させています。表示時は `w / 10` に戻します。例えば学習後の `w` が80なら、気温1℃当たりの係数は8です。

誤差を `e = 予測販売数 - 正解販売数` とすると、学習データn件に対して：

```text
MSE = Σ(e²) / n
dw  = 2 × Σ(e × x) / n
db  = 2 × Σ(e) / n
w   = w - 学習率 × dw
b   = b - 学習率 × db
```

`dw` と `db` は誤差が増える方向とその傾きを表す勾配です。その逆方向に少しずつ動かすのが勾配降下法です。全80件から勾配を計算した後に一度更新する処理を、ここでは1 epochと呼びます。

### 出力の見方

- 学習MSE：学習中に最小化する値。単位は個の二乗です。
- 学習・評価RMSE：MSEの平方根。販売数と同じ個単位で誤差の大きさを見られます。絶対誤差の平均ではありません。
- 基準モデル：学習データの平均販売数を常に返します。気温を使うモデルが単純な予測より改善したか比較します。
- 評価データの正解・予測：未知の入力に対する予測の具体例です。

ノイズがあるので、生成式の係数が厳密に復元されるとは限らず、誤差も0にはなりません。

### 実験

```sh
# ノイズなし：係数8、切片40に近づくか確認
go run ./cmd/linear-regression -noise 0

# 学習不足：デフォルトの2000回と比較
go run ./cmd/linear-regression -epochs 10

# 学習率を小さくする：同じ回数でも収束が遅くなる
go run ./cmd/linear-regression -lr 0.001

# 大きすぎる学習率：誤差が増大し、非有限値になったら異常終了
go run ./cmd/linear-regression -lr 2

# ノイズを増やす
go run ./cmd/linear-regression -noise 50

# データを変える／任意の気温を予測する
go run ./cmd/linear-regression -seed 123 -temperature 28
```

まず1つのパラメータだけを変え、MSEの減り方と評価RMSEを比較してください。生成する気温は0〜35℃です。その範囲外の予測は外挿になります。

この例は「直線で生成したデータに直線を当てる」基礎実験です。過学習を観察するには、次の題材として少数データへの高次多項式回帰が適しています。評価結果を見ながら設定を何度も選ぶ場合は、検証用と最終テスト用を分ける必要があります。

### テスト

ノイズのないデータから既知の直線を復元できること、更新に使う勾配が数値微分と一致すること、HTMLに実行データが正しく埋め込まれることを検証します。
