あなたの数字、読めるかな？

人が書いた数字で学んだ、小さなニューラルネットワーク。自分の字を描いて、学習前と学習後を比べてみてください。

画素の組み合わせから数字を分類

01 / 数字を描いてみる

黒い枠に0〜9を1文字、大きめに描いてください。

モデルが受け取る28×28画素

描画は切り出し・縮小・重心合わせ。
下のテスト画像も入力できます。

「輪があるなら0」のようなルールは書いていません。画素と正解の組から、分類に使う重みを学びました。

02 / ニューラルネットの答え

—

数字を描くか、下の画像を選んでください。

バーはsoftmaxの出力です。正しさを保証する確率ではありません。数字以外の絵も0〜9のどれかに分類してしまいます。

文字の太さや書き方が学習画像と違うと、間違えることがあります。

03 / 知らない数字で試す

最終テストの先頭100枚。クリックすると入力できます。「正解 → 学習後の予測」を表示し、誤分類はオレンジ枠にしています。

04 / 間違いにも注目する

最終テストで最初に間違えた最大36枚。人には簡単でも、モデルが取り違える数字があります。

05 / 学ぶと何が変わる？

各epoch後に、更新に使わない検証5,000枚で測定した正解率です。

epoch検証正解率交差エントロピー損失

損失は正解クラスに高いスコアを割り当てるほど小さくなります。最終テストは学習終了後に評価しています。

06 / どの数字を取り違えた？

行＝正解、列＝予測。対角線が正解した枚数です。最終テスト10,000枚すべてを集計しています。

学習：Go標準ライブラリのみ / 推論：このHTML内のJavaScript。同じ学習済み重みを使います。再学習はGoコマンドで実行します。

データ：MNIST / CVDF配布ミラー（Yann LeCun・Corinna Cortes）。学習画像の一部と評価画像を使用。MNISTの精度は、任意の手描き文字に対する精度を意味しません。
